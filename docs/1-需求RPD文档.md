# 博雅敏格 SEO/GEO 双引擎智能体｜需求 RPD 文档

> 版本 V1.0｜分析日期 2026-07-19｜场景：门窗行业 200+ 城市/经销商内容获客

## 1. 产品目标

围绕城市化搜索意图，持续生产有本地证据的 SEO 长文与 GEO 摘要，经审核后分层分发，监测排名/流量/线索，并把知识沉淀回企业内容中台。先验证广州、深圳、北京，再扩 50 和 200 城市。

## 2. 用户

总部运营维护策略、知识和审核；经销商补充门店/案例/本地证据并处理线索；管理层查看城市、内容、分发和线索效果；访客浏览城市站、门店、文章、FAQ 并预约/咨询。

## 3. 五类智能能力

意图挖掘、内容生产、内容分发、效果监测、知识积累；400 热线作为线索承接渠道。

## 4. 功能需求

| 编号 | 需求 | 优先级 | 验收 |
|---|---|---:|---|
| SG-01 | 城市、词根、意图、热度与内容计划 | P0 | 城市/意图可追溯；计划可审核和去重 |
| SG-02 | 1500—2000 字 SEO 内容、GEO 摘要、Schema 与 RAG | P0 | 引用企业知识；事实不编造；版本留痕 |
| SG-03 | EEAT 证据与信任评分 | P0 | 案例、参数、作者、门店证据；低于 70 不自动发布 |
| SG-04 | L0—L3 分层分发 | P0 | 官网/微信自动，百家号/知乎半自动，XHS/抖音/知道输出内容包；能力诚实标注 |
| SG-05 | 频控与人工审核 | P0 | 单日≤3、单周≤15 等策略可配置；敏感内容人工确认 |
| SG-06 | 城市站、门店、案例、FAQ、域名和 400 热线 | P0 | 归属一致；预约/咨询来源可追踪 |
| SG-07 | 排名、流量、线索归因和运营看板 | P1 | 指标口径明确；城市/内容/渠道可下钻 |

## 5. 当前状态

主站、城市子站、门店/文章/预约/客服、后台 17 个模块、迁移和部署基线已通过现有验收材料；生产域名/TLS、真实模型/地图/发布账号、400 服务和外部平台 UAT 仍需补齐。

## 6. 非功能与合规

多城市内容不得批量生成虚假本地案例；PII 脱敏、RBAC/审计、限流、备份和监控；对外发布必须保留来源、审核和回执。客服 AI 低置信度转人工。

## 7. 依据

依据原 PRD、项目交接、修复与上线验收、README/PRODUCT、Docker/迁移和前后端源码整理。
