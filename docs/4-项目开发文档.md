# 博雅敏格 SEO/GEO 双引擎智能体｜项目开发文档

## 1. 环境

准备 Node、Python、PostgreSQL 16、Redis、Docker。按原仓库 Compose/README 建立本地配置，运行 Alembic 迁移，启动 FastAPI、Next.js 和 Nginx。生产密钥、域名和平台会话只通过环境/Secret 注入。

## 2. 模块地图

公共站点：城市、门店、文章、案例、FAQ、预约与在线客服；后台：意图、内容、知识、审核、分发、线索、客服、指标、城市、门店、SEO、域名、用户、审计和安全。

## 3. 开发约定

- 所有生成内容保存知识版本、引用和本地证据；不得只保存最终文本。
- 新平台先定义 L0—L3 能力和回执契约，再做 UI；半自动内容包不得标自动成功。
- 城市/门店事实必须来自主数据；相似内容、低 EEAT 和超频内容在发布前拦截。
- 数据库只用 Alembic 迁移；API 与 Next 类型同步；外部调用带幂等和可观察重试。

## 4. 测试与发布

沿用现有 pytest、API smoke、17 模块 UI、Next 构建和数据库恢复基线；增加多城市重复、证据缺失、越权、频控、分发失败、客服记忆/转人工、线索归因测试。正式域名、TLS、真实账号与 3 城试点通过后再扩城。

## 5. 合并步骤

先定义城市/门店/经销商/线索的统一 ID；停止两边新增重复表；迁移主数据与历史归因；SEO/GEO 以服务方式接入本地地图中台；完成双读核对后下线本项目重复的用户、门店、线索和看板模块。
