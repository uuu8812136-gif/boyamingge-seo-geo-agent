# DESIGN.md — 博雅敏格门窗前端设计规范

## 设计立场
这是一个门窗/建材品牌的官方网站。设计要传达"工艺感、可信赖、本地服务"，
不是科技感、不是廉价电商。视觉锚点是材料（铝型材、玻璃、密封胶）和工艺（测量、安装、验收）。

## 色彩（:root CSS 变量）
| 变量 | 值 | 用途 |
|------|-----|------|
| --ink | #141210 | 主文字（深炭黑，非纯黑） |
| --ink-soft | #4a4540 | 次要文字 |
| --ink-muted | #8a8278 | 辅助文字 |
| --paper | #f7f5f2 | 页面底色（暖纸色） |
| --surface | #ffffff | 卡片/表面 |
| --accent | #c45c26 | 品牌主色（砖红/赤陶） |
| --accent-dark | #9a4520 | 主色深色（hover） |
| --green | #2f6b52 | 成功/已验证状态 |
| --red | #b83d32 | 错误/失效状态 |

不使用：纯黑 #000、纯白 #fff 做大面积底色、霓虹色、渐变彩虹。

## 字体
- 正文：PingFang SC / Microsoft YaHei，line-height 1.65
- 标题：同字族，靠字重和字号拉开层级
- 不引入额外字族（中文 web font 体积大，得不偿失）

## 圆角
- --radius: 16px（卡片）
- --radius-sm: 10px（按钮、输入框）
- 不用超大圆角（24px+），不用胶囊形（border-radius:9999px）做主按钮

## 间距
- section 间距 80–120px（桌面）/ 48–64px（移动）
- 卡片内边距 24–32px
- 按钮内边距 14px 24px

## CTA 层级
1. **主 CTA**：`.btn btn-primary`（砖红底白字）— 预约测量、立即发布
2. **次 CTA**：`.btn btn-ghost`（透明底边框）— 电话咨询、预览
3. **文字链接**：`.link-arrow` — 查看详情、了解更多
- 每个视区最多 1 个主 CTA，避免争夺注意力

## 动效
- 滚动揭示：`.reveal` + `.reveal--in`，opacity + translateY
- 缓动：`--ease-spring: cubic-bezier(0.22, 1, 0.36, 1)`
- **必须**尊重 `prefers-reduced-motion: reduce`（已有全局处理）
- 不用弹跳、旋转、闪烁等廉价动效

## 状态设计
| 状态 | 处理 |
|------|------|
| 加载 | 顶部进度条 `.admin-loading-bar` 或骨架屏，不用全屏 spinner |
| 空 | `.admin-empty` 文案引导行动（"暂无内容，点击新建"），不只说"空" |
| 错误 | 明确原因 + 下一步（"cookie 已过期，请重新扫码"），不静默 |
| 成功 | toast 提示 + 状态色 pill（绿色） |

## 客服浮窗（全站左下角）
- 固定左下角，不遮挡主 CTA（主 CTA 在右下或表单内）
- 收起态：圆形/圆角方形小按钮，headset 图标，aria-label="联系客服"
- 展开态：小面板，热线 400-888-6688 + 预约测量入口 + 关闭
- 移动端 `safe-area-inset-bottom` 避让
- 不用玻璃拟态（backdrop-filter），用实色 surface + shadow

## 平台能力展示
| tier | 含义 | 颜色 | 可创建任务 |
|------|------|------|-----------|
| verified | 已用真实账号回归验证 | 绿色 | 是 |
| beta | 已接入但选择器未实测 | 橙色 | 是（标注"未实测"） |
| planned | 待接入 | 灰色 | 否（禁用） |
