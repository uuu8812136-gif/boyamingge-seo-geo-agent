# 图片资源说明

后续如有真实项目照片，可放入对应目录，并在前端数据文件中接入。当前页面使用 CSS 绘制的门窗场景，不依赖图片文件。

## 目录结构

| 路径 | 用途 | 建议尺寸 |
|---|---|---|
| `cases/guangzhou-*.jpg` | 广州案例封面 | 800×600 |
| `cases/shenzhen-*.jpg` | 深圳案例封面 | 800×600 |
| `cases/beijing-*.jpg` | 北京案例封面 | 800×600 |
| `hero/window-scene.jpg` | 首页首屏右侧场景图 | 960×720 |
| `stores/` | 各城市门店外观 | 800×500 |

## 当前状态

如需接入照片，可在 `lib/site.ts` 或 `lib/cities.ts` 为案例补充图片字段，例如：

```ts
image: '/images/cases/guangzhou-tianhe-01.jpg'
```

## 拍摄建议

- 安装完成后的窗框整体照（含室内视角）
- 型材截面、五金特写（可选）
- 门店门头或接待区（增强信任感）
- 注意业主隐私：小区名可模糊处理
