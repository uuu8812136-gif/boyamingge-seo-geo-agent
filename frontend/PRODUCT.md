# PRODUCT.md — 博雅敏格门窗 SEO/GEO 平台

## 产品定位
博雅敏格门窗的官方网站与运营后台。面向业主提供系统门窗、旧窗改造、阳台封窗、
防盗门等产品的本地化服务，以多城市二级域名站群形式覆盖广州、深圳、北京等城市。

## 目标用户
- **C 端业主**：25–50 岁，装修或换窗阶段，关注本地门店、实测报价、施工质量、售后质保。
- **B 端运营**：总公司管理员、城市管理员、门店管理员，负责内容发布、线索跟进、SEO 运营。

## 核心价值
1. **本地化信任**：每个城市站展示本地门店、本地案例、本地工程师上门测量。
2. **实测报价**：不在线上给虚价，引导业主预约上门测量后出方案。
3. **SEO/GEO 双引擎**：按城市 + 意图生成内容，覆盖"广州防盗门""深圳封阳台"等长尾词。
4. **多城市分权管理**：总公司统一管控，城市/门店管理员只能操作本区域内容与线索。

## 转化路径（唯一主线）
```
城市站首页 / 文章页 → 客服浮窗 / 电话 / 预约测量按钮 → 留资表单 → 门店跟进 → 上门测量 → 签约
```
所有页面 CTA 都指向这条路径，不设分支。

## 关键页面职责
| 页面 | 职责 |
|------|------|
| 首页 | 建立品牌信任，展示服务能力，引导预约 |
| 城市页 | 证明本地服务能力，展示门店/案例，引导预约 |
| 文章页 | 解决选购/安装疑问，内联 CTA 引导预约 |
| 后台-发布 | 站内内容发布 + 外部平台分发 |
| 后台-线索 | 线索查看与状态跟进 |
| 后台-城市/门店 | 多城市分站与门店管理 |

## 不做什么
- 不做电商交易（门窗需实测定制，不适合线上下单）。
- 不做用户注册登录（C 端只需留资，不需账号）。
- 不做虚假承诺（"最低价""包满意"等话术禁用）。
