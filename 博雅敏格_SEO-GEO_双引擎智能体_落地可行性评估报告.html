核心结论

博雅敏格 SEO-GEO 双引擎智能体的产品愿景清晰、商业逻辑成立——门窗行业高客单、强本地化、决策链长的特征，天然适合"总部内容中台 + 经销商本地承接"的模式。然而，原 PRD 存在三大结构性问题：①多平台自动分发不可行（6/10 个平台无官方 API）；②MVP 范围过大（相当于 6 个独立产品）；③里程碑周期偏乐观 50-80%。

本方案提出五大核心转变：分发策略降级、MVP 收缩为 3 城单链路验证、GEO 策略分阶段、周期合理化、建立内容质量防火墙。执行后综合可行性从 62 提升至 78 分。

策略一：分发策略从"全自动"转为"内容中台 + 分层分发"

原策略
全平台自动分发 — 7+ 平台 API 直连，零人工干预
→
修订策略
内容中台 + 四级分发 — 按平台 API 可用性分层，核心平台自动、其余辅助

四级分发体系

层级定义覆盖平台人工参与
L0 全自动 系统 API 直连，零人工 官网 CMS、微信公众号 无
L1 半自动 系统生成+预填，人工确认后通过官方工具发布 百家号、知乎 1 次确认

L3 观望 等待平台开放 API 或达成商务合作 百度文库、百科、悟空问答 暂不投入

百家号专项攻坚

百家号是百度生态 SEO 价值最高的分发渠道，200 城矩阵效率是核心瓶颈。建议三步走：

Step 1：商务合作

以"全国 200 城品牌矩阵"为筹码，通过百度营销/百家号企业服务申请 API 权限。品牌蓝 V 企业有概率获得批量管理接口。

Step 2：浏览器插件

若 API 不可得，开发"百家号助手"Chrome 插件——经销商安装后，系统自动将内容填入百家号发布表单，经销商仅需点"发布"。比 RPA 更合规。

Step 3：总部代运营

Top 30 高价值城市的百家号由总部统一管理，经销商仅提供素材。减少 200 个非标准操作节点的风险。

策略五：建立三道内容质量防火墙

防火墙 1：EEAT 评分门控

每篇 AI 生成内容必须通过 EEAT 评分后才允许发布：

E 经验：引用 ≥1 个本地真实案例 → ≥60 分
E 专业：包含 ≥3 个具体参数 → ≥60 分
A 权威：标注作者身份 → ≥50 分
T 可信：广告法审核+价格标注 → ≥70 分
综合 ≥70 分方可发布

防火墙 2：发布节奏控制

避免触发百度"大量低质内容"检测：

单站日均发布 ≤ 3 篇
单站周新增 ≤ 15 篇
同模板页面相似度 ≤ 70%
新站首批页面 ≤ 20 篇

防火墙 3：人工内容增强

AI 生成内容必须混入"不可伪造"的真实元素：

≥2 张本地实拍图（非网图）
≥1 条真实业主评价（带小区名+户型）
≥1 个本地化数据点
页尾嵌入经销商信息卡（Schema LocalBusiness）
